#  Personal Portfolio - Daniel Pazmiño

Este es mi portafolio profesional desarrollado como parte de mi formación en **Ingeniería en Sistemas de la Información (UIDE)**. El sitio está diseñado bajo una estética *Dark Engineering*, priorizando la semántica HTML5 y un diseño responsivo con CSS3 moderno.

##  Tecnologías Utilizadas

* **HTML5 Semántico:** Estructura optimizada para accesibilidad y SEO (header, nav, main, section, article, footer).
* **CSS3 Custom Properties:** Uso de variables nativas para una gestión eficiente de temas y colores.
* **Grid & Flexbox:** Layouts dinámicos y adaptables a cualquier dispositivo.
* **Google Fonts:** Tipografías 'Syne' y 'Space Mono' para un estilo técnico/terminal.

## Proyectos Destacados

1.  **Book Management System:** Backend robusto desarrollado en **Go (Golang)** para la gestión de bibliotecas digitales.
2.  **ParryMinute Prototype:** Minijuego de precisión mecánica desarrollado en **Unity & C#**, enfocado en sistemas de combate *soulslike*.
3.  **Fusée Gelée Analysis:** Investigación académica sobre vulnerabilidades de hardware (Root of Trust) en el SoC NVIDIA Tegra X1.
